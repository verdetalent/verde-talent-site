Our Team:

We have an amazing opportunity as the Lead Engineer, Development, Security and Operations (DevSecOps Engineer).   This critical role is responsible for managing Azure cloud infrastructure, leveraging foundational cloud concepts, networking, identity, security, storage, and computer services. The Lead Engineer will support the infrastructure build, manage Continuous Integration, Continuous Deployment (CI/CD) pipelines, utilize Infrastructure as Code using Harness and Terraform, apply DevSecOps principles while implementing security and compliance protocols.

The Lead DevSecOps Engineer will lead the technical execution of our application landing-zone and Internal Developer Platform (IDP) initiatives — enabling product teams through automation, governance, and reusable patterns. The ideal candidate combines deep Azure and DevOps expertise with a passion for building scalable, developer-focused platform solutions.

Essential Functions:

Platform Architecture & Automation

  • Design, implement, and maintain Azure application landing zones using Infrastructure as Code (Terraform).
  • Build and evolve the Internal Developer Platform (IDP) leveraging Harness, Backstage, and related frameworks to deliver developer self-service and standardized onboarding.
  • Engineer and optimize CI/CD pipelines using Harness, Jenkins, Azure DevOps, and GitHub Actions — delivering reliable, compliant, and automated application deployments.
  • Implement GitOps and advanced container orchestration techniques across Azure Kubernetes Service (AKS), OpenShift, and Docker.
  • Ensure end-to-end automation, observability, and security integration within deployment pipelines.

Engineering Enablement & Leadership

  • Serve as a technical lead and mentor, guiding engineers and citizen developers in modern DevOps, IaC, and automation practices.
  • Partner with application teams to deliver reusable pipeline templates, landing-zone modules, and catalog items that accelerate time to value.
  • Lead cross-functional collaboration between development, operations, and security teams to embed DevSecOps, FinOps, and governance best practices.
  • Influence platform roadmap decisions and contribute to strategic initiatives within the Cloud Transformation Group (CTG).

Operations & Continuous Improvement

  • Lead efforts around monitoring, observability, and reliability engineering using Azure Monitor, ELK Stack, Prometheus, or Grafana.
  • Drive performance tuning, cost optimization, and operational hygiene across environments.
  • Participate in incident response, root-cause analysis, and proactive prevention strategies.
  • Support modernization and migration projects that improve cloud scalability, resilience, and compliance.

Technical Knowledge/Skill/Education/Licenses/Certifications:

  • Cloud & DevSecOps Expertise: Proficient in Microsoft Azure and hybrid cloud architecture with strong knowledge of DevSecOps principles, CI/CD pipelines using Harness, and version control using GitHub including branching strategies.
  • Infrastructure Management: Experienced with Infrastructure as Code (IaC) using Terraform, configuration management with Ansible, and artifact management through JFrog Artifactory.
  • Cost Management & Optimization: Understanding of cloud cost models, billing structures, and usage analysis, with hands-on experience using Harness Cost Management and Turbonomics to recommend optimizations.
  • Infrastructure & Configuration Management: Experienced with Infrastructure as Code (IaC) using Terraform, configuration management with Ansible, and artifact management through JFrog Artifactory.
  • Containerization & Orchestration: Skilled in containerization with Docker and orchestration using containers for scalable application deployments.
  • Monitoring & Scripting: Proficient with monitoring and logging tools such as Splunk, AppDynamics, Prometheus, and Grafana, and scripting in Bash, PowerShell, and Python.
  • Strong knowledge of DevSecOps principles, compliance-as-code, and secure cloud architectures (NIST, CIS, SOX frameworks).
  • Demonstrated ability to mentor teams, influence technical direction, and drive platform-level improvements.
  • Experience designing and supporting Internal Developer Platforms (IDPs) or developer self-service portals (Harness IDP, Backstage, Port, etc.).
  • Familiarity with Microsoft .NET Core is a plus.

Education:

  • Bachelor’s degree in computer science, related technical discipline or related experience.
  • Advanced degree desirable.

Experience:

  • Minimum of eight (8) to ten (10) years in a technical engineering role or related experience working with technology or application solutions, including experience in architecture, design, implementation, support, and management of the technologies appropriate for the specific positions.

Working Conditions:

  • Must be available to work emergency restoration assignment as required.
  • Must be available to travel between MA/CT/NH as necessary.
