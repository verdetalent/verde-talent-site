ROLE SUMMARY

We are looking for a hands-on Developer Productivity and Reliability Engineer to build the internal engineering platform, automation, and quality systems that enable teams to deliver software quickly, safely, and reliably.

The role will own reusable infrastructure patterns, CI/CD pipelines, automated testing, environment provisioning, deployment workflows, observability, and developer self-service capabilities across our Python/Django, Go, and Angular/TypeScript applications running on Azure.

The engineer will help establish a modern platform-engineering model based on automation, Infrastructure as Code, measurable reliability, reusable golden paths, and fast developer feedback. This role will work closely with engineering, QA, architecture, security, and product teams.

KEY RESPONSIBILITIES

Developer Productivity and Internal Platforms

  • Build and operate reusable developer workflows that simplify build, test, deploy, troubleshoot, and release activities.
  • Create self-service workflows for project setup, environment provisioning, database initialization, test execution, deployment, and diagnostics.
  • Develop reusable repository templates, pipeline templates, Terraform modules, container templates, and engineering tooling.
  • Establish "golden paths" for common application types and deployment scenarios.
  • Improve local development environments using consistent tooling, containers, service emulators, and documented workflows.
  • Reduce developer cognitive load by standardizing common infrastructure, deployment, testing, and observability patterns.
  • Provide clear feedback through pipeline reports, deployment status, test evidence, quality dashboards, and actionable failure diagnostics.

Infrastructure as Code and Cloud Automation

  • Design and maintain Azure infrastructure through Terraform and version-controlled Infrastructure as Code.
  • Build reusable, composable, and versioned Terraform modules for application, networking, identity, storage, databases, monitoring, and security services.
  • Automate infrastructure validation, policy checks, drift detection, security scanning, and controlled promotion across environments.
  • Implement environment provisioning and teardown workflows, including short-lived or ephemeral environments where appropriate.
  • Automate application deployments using Docker and Azure services such as Container Apps, Functions, storage, networking, identity, and monitoring.
  • Establish safe deployment patterns, including blue-green or canary releases, health checks, automated rollback, and progressive delivery.
  • Manage configuration and secrets securely using appropriate Azure services such as Key Vault and managed identities.
  • Improve infrastructure consistency across development, test, staging, and production environments.

Reliability Engineering

  • Define and implement service-level indicators, service-level objectives, and reliability dashboards for critical applications and delivery systems.
  • Establish production-readiness standards covering availability, performance, scalability, resilience, observability, backup, recovery, and operational ownership.
  • Instrument applications, pipelines, infrastructure, and deployment workflows with logs, metrics, traces, alerts, and diagnostic context.
  • Analyze incidents, recurring failures, deployment problems, flaky tests, and operational toil; drive permanent corrective actions.
  • Support incident response, root-cause analysis, post-incident reviews, and reliability improvement plans.
  • Improve mean time to detect, mean time to recover, deployment success rate, and change failure rate.
  • Introduce resilience and failure testing for important services and infrastructure.
  • Automate health checks, smoke tests, rollback decisions, and post-deployment verification.

CI/CD and Release Engineering

  • Design and optimize Azure DevOps pipelines for fast, reliable, repeatable builds and releases.
  • Implement pipeline stages for validation, compilation, unit testing, API testing, security scanning, container image creation, infrastructure validation, deployment, and post-deployment verification.
  • Use dependency and build caching, parallel execution, selective test execution, and incremental pipelines to reduce feedback time.
  • Establish quality gates based on test results, coverage, security findings, code quality, infrastructure validation, and release risk.
  • Support Git-based development workflows, pull-request validation, branch policies, artifact versioning, and release traceability.
  • Automate release evidence, test reports, deployment records, and compliance-related documentation.

Test Automation and Quality Engineering

  • Define a layered testing strategy across unit, integration, API, contract, component, and end-to-end testing.
  • Build and maintain Playwright-based UI and regression suites with traceability, screenshots, videos, logs, and failure diagnostics.
  • Improve test reliability through deterministic test data, service virtualization, isolation, parallelization, and environment management.
  • Automate test data creation and cleanup for MySQL, PostgreSQL, Redis, and dependent services.
  • Reduce flaky tests and ensure failures are classified as product defects, test defects, infrastructure issues, or environmental issues.
  • Partner with engineering and QA teams to make applications easier to test and operate.
  • Explore AI-assisted test generation, test maintenance, failure triage, and coverage analysis with appropriate human review.

REQUIRED SKILLS AND EXPERIENCE

  • Graduate with 5-8 years of experience in platform engineering, DevOps, SRE, CI/CD, test automation, or developer-productivity engineering.
  • Strong experience building internal developer platforms, delivery automation, or reusable engineering tooling.
  • Advanced hands-on experience with Terraform, including reusable modules, remote state, workspaces or equivalent environment strategies, policy validation, and infrastructure testing.
  • Strong Azure experience with services such as Container Apps, Functions, storage, networking, identity, Key Vault, monitoring, and managed databases.
  • Strong experience designing Azure DevOps pipelines and Git-based delivery workflows.
  • Practical experience with Docker, container image lifecycle management, registries, health checks, and deployment automation.
  • Strong understanding of SRE concepts, including SLIs, SLOs, error budgets, observability, incident response, resilience, and operational readiness.
  • Hands-on automated testing experience with Playwright or a comparable framework across API and end-to-end layers.
  • Strong scripting and automation skills in Python and/or Go.
  • Working knowledge of Python/Django, Go services, and Angular/TypeScript applications.
  • Experience with MySQL/PostgreSQL and Redis for test data, environment setup, integration testing, and operational diagnostics.
  • Experience implementing quality gates, security scanning, dependency checks, artifact promotion, and release traceability.
  • Ability to troubleshoot complex failures across application code, pipelines, infrastructure, networking, and cloud services.

PREFERRED SKILLS

  • Kubernetes, Helm, or other container orchestration platforms.
  • GitOps and declarative deployment tools.
  • OpenTelemetry and modern observability platforms.
  • Performance, load, stress, and resilience testing.
  • Ephemeral environments and preview deployments for pull requests.
  • Backstage or similar internal developer portals.
  • Policy as Code using tools such as Open Policy Agent, Checkov, or tfsec.
  • Security engineering integrated into CI/CD and Infrastructure as Code.
  • AI-assisted development, test generation, failure triage, or agent-based engineering workflows.
  • Experience defining developer-platform adoption metrics and engineering effectiveness metrics.
  • Experience working in regulated or enterprise software environments.

SOFT SKILLS

  • Strong ownership of developer experience, platform reliability, and delivery outcomes.
  • Clear communication and the ability to explain infrastructure and reliability concepts to application teams.
  • Pragmatic approach to automation, balancing standardization with team flexibility.
  • Bias for measurement, simplification, and continuous improvement.
  • Strong troubleshooting and systems-thinking abilities.
  • Ability to influence engineering practices without relying on direct reporting authority.
  • Willingness to remain hands-on with code, infrastructure, pipelines, and production issues.

EDUCATIONAL QUALIFICATION

  • Bachelor's or Master's degree in Computer Science, Information Technology, Engineering, or a related field.
  • Equivalent practical experience with a strong record in platform engineering, automation, reliability, or developer productivity may also be considered.

SUGGESTED SUCCESS MEASURES

  • Reduced CI/CD pipeline duration and time to meaningful developer feedback.
  • Increased deployment frequency and deployment success rate.
  • Reduced change failure rate and mean time to recovery.
  • Increased adoption of reusable Terraform modules, pipeline templates, and golden paths.
  • Reduced environment provisioning time.
  • Reduced flaky-test rate and test-maintenance effort.
  • Improved SLO compliance and production observability coverage.
  • Reduced manual release, environment, and operational effort.
