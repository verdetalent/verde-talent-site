Responsible for the administration and support of security system software/hardware either at the Enterprise, Mid-Range or Desktop levels. Knowledge requirements include security principles, theories and concepts at a network and/or application layer, and access control technologies such as firewalls, content scanners, usage monitors, encryption, VPN and wireless.  Provides direct technical support for all requirements in the planning, coordination, programming, and implementation of releases, upgrades or changes to security system software and hardware, and the range of products and productivity tools that support the testing and production environments relating to any associated operating systems. Ensures stable performance of relevant security related hardware/software for the enterprise through performance monitoring and tuning and performs capacity planning.  Ensures system maintenance as well as high level support of the operating system and all the related security software and hardware components. Plans and implements major software upgrades, ensuring change management procedures and methodologies are implemented and followed.
